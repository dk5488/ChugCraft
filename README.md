# ⚡ ChugCraft — Awwwards-Inspired Interactive Web Experience

**ChugCraft** is a motion-driven digital showcase that reimagines the modern e-commerce beverage experience. Inspired by award-winning web design aesthetics, it combines bold brand storytelling with high-framerate kinetic animations.

### 🌟 Key Highlights
- 🎞️ **Fluid Motion Engine**: Powered by **GSAP ScrollTrigger** & **ScrollSmoother** for frictionless parallax depth.
- ✂️ **Advanced Clip-Path Transitions**: Dynamic text and image reveals tied directly to user scroll velocity.
- 🍹 **Interactive Flavor Carousel**: Smooth horizontal showcase dynamically rendering color palettes and assets per flavor.
- 📹 **Pinned Video Storytelling**: Interactive video scrubber and cinematic splash transitions.
- ⚡ **Cutting-Edge Stack**: Built on **React 19**, **Tailwind CSS v4**, and **Vite** for sub-millisecond responsiveness.
